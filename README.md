## Como começar

1. Instale o Go: https://go.dev/dl/ (para conferir, rode `go version`)
2. Instale o VS Code com a extensão **Go**
3. Clone e rode o primeiro exemplo:
   ```bash
   git clone https://github.com/auchoa-dev/FPFEM-ED01.git
   cd FPFEM-ED01
   go run ./aulas/aula01-introducao-go
   ```

## Estrutura

```
aulas/    um main.go por aula
listas/   listas de exercícios com testes (go test)

```
